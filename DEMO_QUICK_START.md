# 🚀 Quick Demo Start Guide

## How to See the Demo Dashboard

### Step 1: Sign Up
1. **Open the Flutter app**
2. **Click "Sign Up"**
3. **Enter these details:**
   - **Email:** `client@gmail.com`
   - **Password:** `demo123456` (or any password)
   - **Username:** `Demo Client` (or any username)
4. **Select "Client" role when prompted**

### Step 2: Automatic Demo Setup
- The system will automatically detect `client@gmail.com`
- Demo data will be populated instantly
- You'll see a success message: "🎉 Demo account created!"

### Step 3: View the Demo Dashboard
- **Sign in** with `client@gmail.com`
- You'll see a **full WMS dashboard** with:
  - ✅ **Live metrics** (Total Orders, Revenue, etc.)
  - ✅ **Sample orders** in different statuses
  - ✅ **Analytics charts** and trends
  - ✅ **Platform breakdown** (Shopify, Etsy, etc.)
  - ✅ **Quick action buttons** for creating orders/products
